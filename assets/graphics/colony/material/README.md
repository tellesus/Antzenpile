# Layered colony material kit

Original Blender sculpt + imagegen surface finish, card 095 (2026-10-03). Editable sources, production scripts and provenance: `tools/art/colony_material/README.md`.

Queen, primitive/developed Nursery, Entrance each have aligned `rear`, `body` and `front` RGBA textures (768×640). Draw contents/worker representatives between body and front; render labels afterward. Auxiliary organs directly share the Queen texture triplet at a smaller functional footprint, with known color/state modulation. Structural bridge (1280×256) and dark substrate (1280×768) embed functions without implying surveyed tunnels. All cavities are empty; no baked occupants, hidden state, particles, UI or runtime lighting.

Only approved known function/state controls maturity, expansion, health tint and conditional organs. Same source-space projection on body/front prevents layer drift. Import metadata is committed; authoring sources are excluded from Godot import. Desktop graphics is the current target; mobile work is deferred, touch-friendly controls remain.
