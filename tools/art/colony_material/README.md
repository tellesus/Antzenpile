# Colony material production source — card 095

Blender **5.2.2 LTS**, offline production only. No runtime Blender/Krita/3D dependency or paid addon. Native app automation is unavailable in this environment; these sources were authored and exported with Blender's own Python/renderer, not GUI painting.

- `colony_material.blend`: original editable sculpt geometry, procedural grain/resin/thread materials, light rig, aligned export camera, organ and substrate collections. No occupants.
- `colony_material_finished.blend`: that sculpt plus six packed, lossless imagegen surface finishes and editable body/front-lip projection polygons. This is explicitly a hybrid sculpt/paint finish, **not an all-procedural render claim**. Queen finish supplies the generic known-organ body; colors/state/contents are separate at runtime.
- `../generate_colony_material.py`: constructs the base source and exports body/front/rear for Queen, primitive/developed Nursery, Entrance, structural bridge and substrate (the auxiliary sculpt remains editable but shares Queen textures at runtime).
- `../finish_colony_material.py`: exports the polished body/front masks and bridge/substrate from packed images. Front boundaries are ordinary editable mesh vertices; body and front use exactly the same camera/UV coordinates.

To export the finished kit without needing external raw PNGs:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' -b tools/art/colony_material/colony_material_finished.blend --python tools/art/finish_colony_material.py
```

Rebuilding the original sculpt uses `-b --factory-startup --python tools/art/generate_colony_material.py`; optional names after `--` limit exports. Then reapply the finished source above. Raw finish PNGs and Blender backup files are ignored because the finished `.blend` already packs the exact image pixels. Do not discard that packed source when rebuilding geometry. `.gdignore` prevents Godot from importing source art.

## Surface finish provenance

Generated by built-in imagegen on 2026-10-03. Local base sculpt renders were edit targets; the player's v2 INWARD concept guided materials, not UI/topology/occupants. Queen finish then guided the other five passes. Every pass required transparent alpha, empty cavities, microscopic wet dark soil, obsidian resin, stretched cellular membranes, selective embedded amber glints and no ants/brood/food/text. Primitive Nursery keeps low coarse protection; developed Nursery adds folded ivory-amber lining; Entrance carries sparse cyan reflected fibres. Bridge requested irregular structural mass rather than parallel wires. Substrate requested no cavities, organs, scenery or hard edge. Generation outputs were visually reviewed; geometry and cuts were composed/exported locally in Blender. No browser-returned art was used as a style source.

The handoff is `antzenpile_computer_use_graphics_handoff_v2.zip`, supplied by the player. The two BASELINE images were diagnostic only; TARGET references established material/depth/darkness. Mobile requirements in that package are explicitly superseded by the player's 2026-10-03 deferral. No reference UI, fictional Storage organ or baked occupants was copied.

Runtime textures under `assets/graphics/colony/material/`: aligned 768×640 organ triplets; 1280×256 bridge; 1280×768 substrate. Rear geometry is deliberately nearly black; front masks occlude a small edge of live contents. State/labels/known-only reveal stay in presentation code. Rendering/export is deterministic from the saved finish source; **regenerating AI finishes is not deterministic**.

## 096 OUTWARD sources

`outward_material.blend` retains an original rugged local Home lip, broad near-ground mesh, grain, light rig and camera. `../generate_outward_material.py` reproduces that sculpt. `outward_material_finished.blend` additionally packs the Home macro surface finish and neutral smoky density mask, with editable projection planes. Export using Blender `-b tools/art/colony_material/outward_material_finished.blend --python tools/art/finish_outward_material.py`; append `-- verify` to use packed inputs only and render into ignored `.godot/card096_source_reexport`.

Home was finished with built-in imagegen from the local sculpt and card-095 Queen material reference, retaining a shallow broad ground band and empty center opening, with charcoal grain/resin/amber membrane and dark cyan side reflections. The prompt excluded distant scenery, ants/occupants, resources, UI and a neon portal. Smoke was generated as a neutral transparent turbulent pearl-gray/white density mask without any object identity, crystals, glitter, text or UI. Both are offline textures; the game supplies anchors, tint, strength, confidence, returned impressions and bounded motion. No runtime volume rendering or lights. Exact image pixels remain packed; AI regeneration is not deterministic.
