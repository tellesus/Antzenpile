# 039 — First Adaptation Web choice (roadmap)

Status: proposed from player feedback; expand to an executable card before implementation.

Bring forward one narrow choice from GDD Part 5. It must spend real protein, brood capacity, nurse labor and simulated development time rather than a research currency. Specify a pair of traits with a meaningful tradeoff against the systems already online. Keep genetic repertoire distinct from expressed workforce traits: existing workers do not change instantly, and new expression arrives through aggregate brood and emergence. Define deterministic effect timing, worker-ledger accounting, save migration, detached INWARD interaction and a concise player explanation.

The player left the first trait pair to implementation judgment. Choose it from tradeoffs grounded in the current game and record the rationale before coding. Do not implement a full tree, rival colonies, caste micromanagement or genome-per-worker state in this card.
