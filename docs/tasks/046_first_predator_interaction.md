# 046 — First predator interaction

Status: roadmap; expand against 045 before implementation. Source: GDD Part 4 §§57–63 and 144.

Add one stationary zone that attacks aggregate trail traffic with bounded saturation. Record physical casualties through the authoritative population API and reconcile cohorts/route commitments. Keep encounters private until survivor returns or a bounded missing-return inference; ordinary UI must not reveal an unobserved predator or instant casualty truth. Expose returned alarm/loss evidence in the selected route and let the player avoid the threat through a specified route/labor response, or knowingly accept the risk. Optional combat is outside this first interaction.

Resolve saturation timing, full-cohort loss, adapted casualty selection, cargo loss, route labor targets and the distinction between true and colony-known worker counts in this card. Verify conservation, delayed evidence, avoidance, pause/speed, legacy saves and exact continuation; inspect the resulting player context before the visual-quality milestone.
