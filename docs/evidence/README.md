# Evidence artifacts

These files record specific builds and probes. Most existing artifacts are **historical evidence only**, not current instructions or proof of release readiness. They remain at this path to preserve Godot/authoring references and unrelated user imports/translations. Narrative records now live in the [archive](../archive/README.md).

For current status use [Current Build](../CURRENT_BUILD.md). New evidence must name its card/build, engine/platform, actual method/results and limitations. A headless result does not establish graphical feel, audio quality or packaged desktop performance. Do not regenerate historical artifacts or overwrite the player's saved slot merely to refresh documentation.
