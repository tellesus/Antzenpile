The player selects C2 as a much better/pretty solid direction and identifies C1's piano sounds as unpleasant. This suite retains C2's warm synthetic key voice and excludes piano recordings, plucks and clustered foreground chord attacks. Longer-form music, transitions, fatigue and the eventual game mix remain listening acceptance.
