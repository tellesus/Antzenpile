Antzenpile systems-beta asset provenance

Game geometry, score and information cues are original project work; licensed
material contributions are identified below. Blender-authored
worker/queen/brood renders and vector art use committed project sources.
Colony and sensory materials include OpenAI imagegen finishes from original
project sculpts. Player reference screenshots are not shipped as backdrops.
No runtime Blender, Krita, sampler, web service or paid addon is required.

The current C2 Warm Current score200 is original project synthesis and arrangement,
using the reproducible pilot198/suite199 production sources. No recorded piano,
VCSL instrument sample, reference track or Freesound recording is used in this
score. Returned information cues remain original project synthesis. Historical
score190 and rustle195 assets are not distributed in this build.

The Godot engine is distributed under its MIT license. Its license and
third-party copyright/license notices accompany this build in
GODOT_LICENSE.txt and GODOT_COPYRIGHT.txt, pinned to Godot 4.7.2.
These notices describe dependencies; they do not relicense Antzenpile.

The excavated local nest relief is original deterministic SVG artwork authored by tools/art/generate_excavated_home.py. It uses no third-party image or runtime dependency.

The current entrance195 supersedes that SVG with original Blender geometry and
offline lighting rendered using Ground054 color/displacement from ambientCG
(Lennart Demes), CC0 1.0: https://ambientcg.com/view?id=Ground054
License: https://docs.ambientcg.com/license/

Original C2 production and cyclic encoding sources are retained under
tools/music/suite199 in the source repository. Blender/Audaspace is used only
for offline compression. No runtime Blender, online audio service or additional
addon is required.

Brood artwork201 is original Blender mesh/lighting work, generated offline by
tools/art/render_brood201.py. The egg, larva and pupa use no third-party model,
recording or paid service. Runtime remains2D with baked transparent sprites.
