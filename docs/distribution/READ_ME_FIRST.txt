ANTZENPILE — SYSTEMS BETA (WINDOWS x86_64)

Extract the entire ZIP, then open Antzenpile.exe in the Antzenpile folder.
Keep Antzenpile.pck beside the executable. No Godot installation is needed.
This is a player-review beta, not the final Windows 1.0 release.

Drag OUTWARD to turn; tap a trace to inspect it. Tab switches INWARD/OUTWARD.
Space pauses; 1/2/3/4 select speed. HELP explains controls. Reports and
Colony Status are in the Colony Menu. SAVE/LOAD or Ctrl+S/Ctrl+L use one slot.
Load deliberately; it replaces the current unsaved run. Sound has separate
music and information-cue levels. End Run shows sampled physical history;
that revealed run cannot resume, and End Run does not overwrite your save.

Saves: %APPDATA%\Godot\app_userdata\Antzenpile\saves\slot_1.json
Sound settings: the same Antzenpile folder, audio_preferences.cfg.
The beta shares these paths with development builds. Saves load only in the
same build that created them. Start a new colony after changing builds.
Previous-build save preservation and migration are tabled until true release
preparation; they are not goals of this development beta.

What to try: start a colony, gather and develop it, queue an adaptation,
respond to a returned warning, continue into a daughter nest, save/reload,
and inspect End Run. Inward functions remain abstract; exterior information
arrives with ants. Screenshots/notes about unclear controls are useful.

Please report your Windows version, CPU/GPU, resolution, graphics/audio
impressions, and any slowdown (especially mature networks at 16x/64x).
Automated simulation/package checks passed; actual graphics, sound, feel,
performance and another-machine acceptance still need player review.

BUILD_MANIFEST.json identifies source revision, engine, resources and hashes.
This beta is unsigned; no signing certificate or installer is included.
